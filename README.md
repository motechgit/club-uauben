# Site du Club des Étudiants de l'U-AUBEN

Site web statique (HTML/CSS) réalisé collaborativement avec Git et GitHub dans le cadre d'un TP.

## Répartition

| N° | Branche | Fichier | Page |
|---|---|---|---|
| 1 | `feature/presentation` | `pages/presentation.html` | Présentation du club |
| 2 | `feature/bureau` | `pages/bureau.html` | Bureau exécutif |
| 3 | `feature/activites` | `pages/activites.html` | Activités |
| 4 | `feature/evenements` | `pages/evenements.html` | Calendrier des événements |
| 5 | `feature/galerie` | `pages/galerie.html` | Galerie photos |
| 6 | `feature/adhesion` | `pages/adhesion.html` | Formulaire d'adhésion |
| 7 | `feature/contact` | `pages/contact.html` | Contact |
| 8 | `feature/faq` | `pages/faq.html` | FAQ |

## Démarrage rapide

```bash
git clone [https://github.com/motechgit/club-uauben.git]
cd club-uauben
git switch feature/<votre branche ou page>
cp pages/_modele.html pages/<page>.html
```

Voir [CONTRIBUTING.md](CONTRIBUTING.md) pour les règles de contribution.

## Tester en local

Ouvrir `index.html` dans un navigateur, puis cliquer sur sa page dans le menu.
